# 与 ds2api 的功能对齐

参考：本地 `ouqiting20/ds2api` 的 `f9d2085`。本轮在已有 Android 请求、文件上传和提示词实现之上补齐共享业务功能。

| 功能 | 当前行为 |
| --- | --- |
| 弹性号池 | 按优先级选取账号，支持按 default/no_tools/tools_only 分池；保护在途请求；不可用账号让出名额 |
| 账号状态 | 登录拒绝、鉴权连续失败、上游封禁、禁言、验证码冷却持久化；成功登录可清除鉴权失败；验证码只识别并冷却，不自动解题 |
| 手动禁用 | 与弹性休眠分开记录，弹性重算或登录成功不会重新启用管理员手动关闭的账号 |
| 到期恢复 | 禁言/冷却到期自动重算号池；启动时也会重新选择可调度账号 |
| 分钟/每日额度 | 每账号限额；每日使用 GMT+8 自然日；计数跨队列重建、休眠/启用保留；关闭每日限额会清空其计数 |
| 独立用量账本 | OpenAI Chat/Responses、Claude、Gemini 和 Vercel 租约完成路径接入；关闭聊天记录仍记用量；首次从旧聊天记录补账 |
| 用量后台 | 日期和调用方筛选、图表、CSV 导入导出、计价与峰谷设置；账本与聊天记录分别存储 |
| 账号管理 | 分池、优先级、状态筛选、手动令牌、节点绑定、封禁账号批量删除 |
| 保活 | 可配置开关、间隔和提示词；与普通请求协调并发；只删除保活创建的单个会话 |
| 语音合成 | `/v1/audio/speech` 和 `/audio/speech`，GET/POST；DeepSeek TTS ticket/WebSocket、音色选择和 Ogg/WAV 处理；附后台测试页 |
| Mihomo 桥 | 订阅、节点、运行时配置、测速结果、账号绑定和故障节点转移；代理客户端刷新和失败反馈接入 Android 客户端 |
| 管理员初始化 | 未设置管理员密码/哈希时初始化随机密码并保存哈希；启动输出初始密码；不继续使用公开固定初始密码 |
| 后台页面 | 用量、语音、代理桥、主题切换和导航深链 |
| 配置扩展 | 设置和段注册表统一驱动读取、校验、导入与后台表单；保留已有提示词开关 |

## Android 设备档案

继续使用原项目的 Android 请求，不改为网页协议。首次使用托管账号时补齐型号、Android API 等级和 32 字节 Base64 设备 ID。当前有 25 个型号、47 个型号/API 组合。具体值可由账号字段或 `DS2API_DEEPSEEK_DEVICE_MODEL`、`DS2API_DEEPSEEK_ANDROID_API_LEVEL`、`DS2API_DEEPSEEK_DEVICE_ID` 环境变量指定；账号字段优先。

可写配置会保存分配结果，同一账号后续复用；环境配置只读/Vercel 使用按账号稳定派生的后备档案。账号休眠、禁用和更新其他配置不会清掉 Android 设备字段。账号管理的“设备 ID 管理”显示当前页设备档案，可修改或清空字段；空字段下次使用时自动补齐。API 等级是 Android API 数字，例如 35/36，不是系统版本号字符串。

参考项目可选的网页数美 SDK 设备生成没有接入，Android 档案也不代表由 SDK 签发的真实设备认证材料。后台隐藏该 SDK 模式选择；旧设备池接口为配置兼容保留，SDK 刷新在缺少实现时返回 501。

## 启用和存储

- 保活沿用参考项目默认：未设置时开启，账号被正常请求使用后安排定时保活，可在设置页关闭。示例配置显式关闭保活。Mihomo 需显式启用。验证过程中没有调用真实账号或节点。
- Mihomo 需要部署环境提供相应可执行程序和有效订阅；本轮未下载、启动真实代理内核。
- 显式账号 `no_proxy=true` 使用直连客户端，覆盖账号代理并避开环境代理。
- 用量账本默认在 `data/usage.json`，可用 `DS2API_USAGE_PATH` 指定。
- 每日额度默认在 `data/account_daily_limit.json`，可用 `DS2API_ACCOUNT_DAILY_LIMIT_PATH` 指定。
- 关闭进程时停止保活/代理桥、关闭客户端空闲连接，并刷新用量和待写入的每日计数。
- 已有管理密码和已配置的 `DS2API_ADMIN_KEY` 继续生效。首次随机密码仅在没有现成凭据时初始化。

## 验证范围

Go 单元测试覆盖账号恢复、设备档案保存与只读派生、登录请求身份一致、分钟/每日额度、用量独立于历史、保活单会话删除、语音编解码和 WebSocket 帧。Node 测试覆盖原有提示词/工具流与新增设置、主题、节点和用量 CSV/图表注册。后台另运行生产构建。

本轮未使用真实 DeepSeek 账号联调 TTS、保活或故障转移，也未验证网页 SDK 设备生成。HAR 无法验证的 TLS/HTTP2 指纹边界继续以 `android-har-alignment.md` 为准。本轮修正了现有 OkHttp 预设缺少 ALPN 时无法协商 H2 的问题；未声称该预设与 Android 36 实测握手一致。

最终验证：54 个 Go 测试包、276 项 Node 测试通过；账号、鉴权、配置、请求客户端、保活、用量、Mihomo、语音及路由相关的 race 检查通过；lint 无问题；后台生产构建成功。构建提示用量图表包超过 500 kB，为体积提示。环境没有可运行的 Chromium，本轮未做浏览器视觉验收。
