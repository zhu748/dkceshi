## 实施原则

- 共享业务不依赖 HTTP 协议目录；协议格式只在适配和渲染边界处理。
- 迁移现有实现和测试，不同时改写解析语法、提示词规则或重试语义。
- 按职责和依赖拆分，不为达到行数任意截断函数，也不引入循环依赖或动态注入解析函数。
- 兼容入口仅在有真实调用方时保留；不增加只有转发用途的内部包装。
- 门禁允许现存未拆分的大文件保持当前大小，但不允许它们继续增长；每次拆分后收紧上限。

## 第四轮：Node 租约生命周期与账号批量测试

| 方向 | 发现与处理 |
| --- | --- |
| 401 恢复标记 | Node 重试构造了 `auth_failed` 却未编码发送，Go 无法进入共享凭据恢复分支；补齐标志，并把 prepare / PoW / switch 的重复请求编解码合并，`http_internal.js` 299 → 250 行 |
| prepare 异常 / 断开 | 旧版先校验 prepare 字段、后创建释放器，字段不完整时泄漏租约；断开监听也晚于 prepare。现在由独立生命周期模块在 prepare 前监听，收到 lease ID 即登记，异常 / 晚到结果均释放一次 |
