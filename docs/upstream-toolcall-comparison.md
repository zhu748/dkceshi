# 上游工具提示词与格式兜底对比

本次对比固定上游 `ouqiting20/ds2api` 的 `main` 提交
`6d8243634281b7fcd12d338367510a4b881428f9`（4.7.0），以及当前 `ceshi` 的
`7199fd5` 加本会话修改。上游源代码未修改；本轮未提交或推送。

## 提示词内容与注入位置

| 项目 | 上游 | 当前项目及本轮取舍 |
|---|---|---|
| 完整规范 | 首部 system 合入 schema、规则和按工具名选取的固定示例 | 首个 system/developer 合入 schema 和规则；保留按当前 schema 决定参数的行为 |
| 底部提醒 | 明确禁止 DSML；声明仅针对客户端工具 | 今日 `e78b0ff` 曾将 DSML 禁令替换成一般性的“使用展示的前缀”；本轮补回明确禁令及客户端作用域 |
| 最后一条为 assistant | 无论是否声明 prefix，提醒均插在该消息之前，直接继续它的正文 | 仅 `prefix: true` 作为预填充；已完成回答后放提醒，再开启新的 assistant 轮次 |
| 消息边界 | 合并相邻同角色文本，使用连续角色标签 | 保留每条消息、角色、调用 ID 与结束边界；保留本轮已有的结束标记输出保护 |
| 空值及必填参数 | 一般性禁止空参数，Shell 示例固定使用某些字段名 | 保留 schema 允许的空字符串/null/空容器；本轮强调每个 invoke 独立包含全部 required 字段 |
| 标识替换 | 部分路径对完整提示词做全文替换 | 只替换生成的标签前缀，保持用户正文及 CDATA 原值 |
| 旧默认配置 | 非空 prompt 一律视为自定义 | 本轮识别已知旧内置默认原文，升级到新提醒；自定义和关闭状态保留 |

位置变化可以追溯到 `e78b0ff`：`appendToolCallFormatSpec` 增加了 `prefix == true` 判断。
因此整体仍然是“前部完整规范 + 生成点附近的短提醒”，并未改成只在历史中间放置提醒。
普通历史 assistant 与明确的预填充续写有不同位置，这是 API 轮次语义的有意区分。

固定示例没有整体复制。实际使用一个名为 `read_file`、但参数要求 `file_path` 的 schema 回放：
上游注入的名字驱动示例仍示范 `path`；当前项目只展示真实 schema 与通用语法骨架，避免误导。
同样保留当前的大整数精度、大小写敏感工具名校验、required/allowed/none 策略和 Agent 调用结果配对。

## 上游如何处理 DSML

上游同时采用提示词约束和输出兜底，不能将其归为仅靠提示词：

1. 默认底部提醒明确要求禁止生成 DSML 前缀的客户端工具调用。
2. 流式筛分器识别 DSML 块，跨分片缓冲并隐藏，不把内部标签逐片发到正文。
3. 共享收尾从原始输出检测残余工具意图，再发起一次 LLM 格式修复。
4. CDATA 参数通过 DS_SLOT 占位保护；贪婪与按元素边界两种解释用于恢复后重解，避免参数越界吞并。
5. 修复成功后合并调用并删除被替代的坏标记区间；最终还有 DSML 残片清理。
6. 无法修复的普通 EPSE 坏块可能按原文保留；DSML 专用隐藏/清理不等于工具已成功执行。

上游 `internal/toolcall/toolcalls_dsml.go` 实际提供 EPSE 标签归一化；文件名不代表它会直接解析
原生 `DSML calls`。当前项目在共享收尾增加的 `RecoverDSMLToolCalls` 才是完整原生格式的本地恢复。

## 已对齐的兜底与不覆盖的改进

对比时，`internal/toolcall` 下有 13 个生产源文件与上游逐字节相同，涵盖结构化扫描、候选壳归一化、
残余意图、CDATA 边界修复、占位保护与还原等；上游工具解析/筛分/assistantturn 的测试函数名集合
也没有当前项目缺少的新用例。因此本轮没有重复复制整套解析器。

当前保留以下已有改进：完整 DSML 本地恢复、坏块先缓冲再交付、孤立闭合标签清理、
Node 扫描偏移保真、参数 schema 校验、大整数精度，以及修复请求继承取消和有界异步会话清理。
这些功能不能为了恢复旧提示词而退回上游旧路径。

对同一份历史 ZIP 关闭远程修复做离线对照，上游直接解析出 18 个主流程调用，4 个 DSML 回合需要
远程修复；当前共享收尾在本地得到全部 24 个调用。这 4 个回合与记录内远程修复结果的工具名、
参数类型和值摘要一致。该结果说明本地格式恢复有效，不是提示词已经在线证明消除了 DSML 漂移。

## 本轮验证

新增回归覆盖旧默认提醒升级、自定义和关闭状态保留、普通回答/预填充的提醒位置、随机标识一致性、
以及不按工具名虚构参数示例。共享提示词继续用于 Chat、Responses、Claude、Gemini 和 Vercel prepare。
