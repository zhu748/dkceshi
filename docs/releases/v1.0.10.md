# v1.0.10

- 请求用量优先采用上游真实计数。成功生成后按会话和消息 ID 查询消息历史，使用 USER 累计作为输入、ASSISTANT 累计作为合计，两者之差作为输出；查询取消、失败或无法完整配对时才回退估算。
- OpenAI Chat、Responses、Claude、Gemini 和 Vercel 共用用量结果，客户端响应、历史记录与账本保持一致。返回来源及原始计数，保留真实零，避免续写累计值、文件输入和思考分项重复计算。
- 已知上游输入和输出时跳过本地全文 token 计数。消息用量查询最长 3 秒，Vercel 校验、预览及最终结算复用缓存，不重复请求。
- 历史列表增加输入、输出、合计和来源；详情增加思考及上游原始计数，兼容旧记录。失败和中断请求保留可用的部分用量并标明不完整，失败归档不计为成功调用。
- 修复 Claude、Gemini 流式请求漏计引用文件，以及协议转换桥丢失用量来源的问题。Gemini 普通输出与思考分项避免重复相加。
- 核对最新 Android 2.7.1 图片、DOC、HTML、TXT 抓包，补充请求头、上传格式和计数语义说明；脱敏回归夹具只保留消息关系与数值。
- 提供七个平台程序包、配套 Android Web SDK 扩展包、Docker 镜像及离线包，并附 SHA-256 校验文件。

完整口径及回退规则见 [Token 用量说明](../token-usage.md)，扩展包安装见 [Android Web SDK 扩展包](../android-devid-package.md)。
