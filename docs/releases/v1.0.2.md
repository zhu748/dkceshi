# v1.0.2

本版本修复工具调用、格式纠错和上下文转录的保真问题，并发布内置 devid 的 Docker 镜像。

- Claude/Gemini 的原生与 Vercel 路径复用标准请求归一化，保留工具选择、并行限制、调用与结果 ID、错误状态和输出 Schema。
- 格式纠错拒绝删除未命名参数、缺失工具名的调用和未归属正文；重复 XML 关键属性拒绝解析，避免静默选择或交付部分调用。
- CDATA 字符串在历史重建和宽松 Schema 中保留原类型、空白和精度；普通文本、业务 ID 不再被误收集为附件引用。
- Responses 保留拒绝信息、预填充边界、内容顺序和文本空白；Gemini 正确区分正文与思考，并支持 nullable、SDK 数量边界和数值枚举转换。
- 超过 32K 字符的首轮用户正文可以在前置指令存在时完整外置；活动工具循环保持完整，响应记录保留真实用户任务。
- GHCR 镜像内置 Node 24、当前 devid 运行器和已校验 Android Web SDK 静态资源。资源包固定 SHA-256，镜像以非 root 用户运行，设备状态独立保存在 `/data/devid-state`。

## Docker

```sh
docker pull ghcr.io/zhu748/dkceshi:v1.0.2
```

支持 `linux/amd64`、`linux/arm64`；同时提供 `1.0.2` 和 `latest` 标签，以及可用 `docker load` 导入的分架构镜像压缩包。普通 Compose 已使用本仓库镜像并持久化设备状态。后台将设备 ID 来源设为 auto 后使用内置资源。

内置的是 Android 浏览器环境适配的 Web SDK；离线自检验证载荷生成，不代表真实账号登录或云端设备 ID 签发已经验证。二进制压缩包附带运行器，非 Docker 部署可使用配套 `devid-android-websdk_v1.0.2.zip` 安装资源。

验证覆盖 Go/Node 完整测试、格式与静态检查、文件行数门禁、WebUI 构建和多平台发布构建。发布流程还会在镜像构建时及推送后运行 devid 离线自检。
