# 设备 SDK、协议边界与生命周期优化

基线：`ceshi` 分支 `f961d88`。本轮以已复现缺陷为优先级，补充回归后同步实现、运行文件和文档。

## 已完成

| 范围 | 行为变化 |
| --- | --- |
| 设备档案隔离 | 按账号 SHA-256 命名；只迁移没有当前账号冲突的旧文件；删除账号同时清理 SDK 与旧设备档案 |
| 生成事务 | 临时档案生成，成功后核对设备、路由及账号版本；拒绝删除重建后的旧结果；配置保存失败回滚内存及档案 |
| 并发与取消 | 登录、单次及批量刷新共享两槽并发限制；账号锁可取消并自动回收；批量使用有界 worker |
| SDK 网络 | Node 离线采集，Go 按账号代理 / 环境代理 / 显式直连策略提交；限定 SDK 服务地址并过滤 App 凭据头 |
| 安装与自检 | 资源白名单安装、摘要校验、SDK 语法及真实离线载荷自检；修复计时精度的随机误判；保留当前脚本；旧覆盖脚本执行前拒绝 |
| 设备参数 | Go / Node 共用 vivo 规格；补全 API 24–37 映射；支持复用档案的屏幕/GPU 校准；按 IANA 计算动态时区偏移；Go 嵌入时区数据 |
| 协议边界 | Responses 工具批次保留全部思考片段；统一账号不可用的 429 分类；Gemini 在 UTF-8 边界截断；分页避免整数溢出 |
| 前端生命周期 | API 测试器与设备、账号操作取消后不接收过期结果；旧 finally 不覆盖新请求；SSE 支持分片 UTF-8、CRLF、多行、EOF 尾帧及真实结束原因 |
| HTTP/2 | 已完整消费的连接按 origin、token、安装身份和代理客户端隔离复用；在途请求独占连接；关闭池后丢弃晚到归还 |
| 部署与职责 | 提供可选 SDK Docker 目标、只读资源挂载和独立状态卷；所有 Release 平台携带运行脚本；TTS、SDK 和前端请求按职责组织 |

SDK 原始 `fp-1.min.js` 资源未修改，账号和已有 ID 不打入资源包或发布归档。默认设备 ID 来源仍为 manual。
更新原始 v1 包时用安装器导入资源，避免解压覆盖当前生成器。操作和环境变量见 [Android SDK 接入说明](android-devid-package.md)。

## 验证

- Go 全量单测：57 个有测试包通过。
- Node：416 项通过，含本地附件资源的 SDK 离线集成；0 失败、0 跳过。没有外部 SDK 资源的 CI 会跳过两项资源集成用例。
- Go lint：0 issues；源码大小和 Node 语法门禁通过；WebUI 生产构建通过。
- Race：auth、config、devid、deepseek client、transport、admin accounts、promptcompat、completionruntime、audio 九个包通过。
- 发布目标：Linux amd64/arm64/armv7、macOS amd64/arm64、Windows amd64/arm64 七个目标交叉编译通过。
- 本地 Linux Release 归档包含运行脚本、规格数据和安装器，未包含设备档案；SDK 重新打包和安装器验证通过。
- TTS 迁移逐函数比较 AST 格式化函数体，保持原有逻辑；连接复用回归验证同身份六个连续请求使用一条连接，并覆盖取消与池重置。

上述结果不代表真实 DeepSeek 登录、云端设备签发或生产负载已经验证。当前环境没有 Docker，SDK 镜像未实际构建；Compose 文件已解析、构建目标和资源路径已复核。
